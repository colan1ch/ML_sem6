## 1. Постановка задачи (Вариант 1.10)

**Исследовать на экстремум функцию:**


$$f(x) = (10\ln x_1 - 2)^2 + 10(x_2^2 + 2)^2 - 10 \rightarrow \text{extr}$$

**При ограничениях:**
$$\begin{cases}
g_1(x) = x_1^2 + x_2^2 - 2 \le 0 \
g_2(x) = -x_1 \le 0 \
g_3(x) = -x_2 \le 0
\end{cases}$$

*Примечание: Так как целевая функция содержит $\ln x_1$, область определения требует $x_1 > 0$. Следовательно, ограничение $g_2(x) = -x_1 \le 0$ всегда является строго пассивным ($x_1 \neq 0$).*

## 2. Пошаговое исследование

### Шаг 1-2. 

Составление функции Лагранжа и необходимых условий 

Поскольку мы ищем регулярные точки, положим $\lambda_0 = 1$ и запишем классическую функцию Лагранжа:


$$L(x, \lambda) = (10\ln x_1 - 2)^2 + 10(x_2^2 + 2)^2 - 10 + \lambda_1(x_1^2 + x_2^2 - 2) + \lambda_2(-x_1) + \lambda_3(-x_2)$$

Выпишем систему необходимых условий первого порядка (условия Куна-Таккера):

1. 
Стационарность по $x_1$ и $x_2$:



$$\frac{\partial L}{\partial x_1} = 2(10\ln x_1 - 2) \cdot \frac{10}{x_1} + 2\lambda_1 x_1 - \lambda_2 = 0$$


$$\frac{\partial L}{\partial x_2} = 20(x_2^2 + 2) \cdot 2x_2 + 2\lambda_1 x_2 - \lambda_3 = 0 \implies 40x_2(x_2^2 + 2) + 2\lambda_1 x_2 - \lambda_3 = 0$$


2. 
Дополняющая нежесткость:



$$\lambda_1(x_1^2 + x_2^2 - 2) = 0, \quad \lambda_2(-x_1) = 0, \quad \lambda_3(-x_2) = 0$$


3. 
Допустимость и знаки множителей:



$$g_1(x) \le 0, \quad g_2(x) \le 0, \quad g_3(x) \le 0$$


$$\lambda_1, \lambda_2, \lambda_3 \ge 0 \quad (\text{для минимума})$$



---

Шаг 3. Поиск стационарных точек 

Как мы уже отметили, $x_1 > 0$, поэтому $\lambda_2 = 0$. Рассмотрим возможные случаи для остальных ограничений:

Случай А: Все ограничения пассивны ($\lambda_1 = 0, \lambda_3 = 0$) 

Тогда из уравнения по $x_2$:


$$40x_2(x_2^2 + 2) = 0 \implies x_2 = 0$$

Но если $x_2 = 0$, то ограничение $g_3(x) = -x_2 \le 0$ становится *активным* ($g_3(0) = 0$), что противоречит условию пассивности. Значит, в этой области решений нет.

Случай Б: Активно только ограничение $g_3(x)$ ($\lambda_1 = 0, x_2 = 0$) 

Подставим $x_2 = 0$ и $\lambda_1 = 0$ во второе уравнение стационарности:


$$40(0)(0 + 2) + 0 - \lambda_3 = 0 \implies \lambda_3 = 0$$


Теперь подставим $\lambda_2 = 0, \lambda_1 = 0$ в первое уравнение:


$$\frac{20(10\ln x_1 - 2)}{x_1} = 0 \implies 10\ln x_1 - 2 = 0 \implies \ln x_1 = 0.2 \implies x_1 = e^{0.2} \approx 1.221$$

Проверим точку $x^e = (e^{0.2}, 0)$ на допустимость в первом ограничении $g_1(x)$:


$$g_1(e^{0.2}, 0) = (e^{0.2})^2 + 0^2 - 2 = e^{0.4} - 2 \approx 1.492 - 2 = -0.508 \le 0 \quad (\text{Выполняется!})$$

Получили условно-стационарную точку:


**$x^e = (e^{0.2}, 0)$** при $\lambda^e = (0, 0, 0)^T$.

---

Шаг 4. Проверка достаточных условий экстремума 

Найдем вторые частные производные функции Лагранжа для нашей точки $x^e = (e^{0.2}, 0)$ при $\lambda = 0$:


$$\frac{\partial^2 L}{\partial x_1^2} = \frac{200}{x_1^2} - \frac{20(10\ln x_1 - 2)}{x_1^2}$$


Подставляя $10\ln x_1 - 2 = 0$ и $x_1 = e^{0.2}$:


$$\frac{\partial^2 L}{\partial x_1^2} = \frac{200}{e^{0.4}} > 0$$

$$\frac{\partial^2 L}{\partial x_2^2} = 120x_2^2 + 80 + 2\lambda_1 = 120(0) + 80 + 0 = 80 > 0$$

$$\frac{\partial^2 L}{\partial x_1 \partial x_2} = 0$$

Матрица Гессиана функции Лагранжа (она же второй дифференциал $d^2L$) в этой точке равна:


$$H = \begin{pmatrix} \frac{200}{e^{0.4}} & 0 \\ 0 & 80 \end{pmatrix}$$

Поскольку все угловые миноры строго положительны ($\frac{200}{e^{0.4}} > 0$ и $\text{det}(H) > 0$), второй дифференциал $d^2L > 0$ для любых ненулевых приращений $dx$.

Следовательно, точка **$x^e = (e^{0.2}, 0)$ является точкой строгого условного локального минимума**.

---

Шаг 5. Вычисление значения функции 

Подставим координаты точки в целевую функцию:


$$f(e^{0.2}, 0) = (10\ln(e^{0.2}) - 2)^2 + 10(0^2 + 2)^2 - 10$$

$$f(e^{0.2}, 0) = (2 - 2)^2 + 10(4) - 10 = 0 + 40 - 10 = 30$$
