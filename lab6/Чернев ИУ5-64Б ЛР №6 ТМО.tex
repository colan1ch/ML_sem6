\section*{Цель работы}
\begin {enumerate}
\item Исследование необходимых и достаточных условий существования экстремума функции с учетом ограничений (условный экстремум).
\item Вычисление экстремумов функции.
\end {enumerate}
\section*{Постановка задачи}
Исследование необходимых и достаточных условий существования экстремума функции с учетом ограничений (условный экстремум) с целевой функцией:
$$f(x) = (10\ln x_1 - 2)^2 + 10(x_2^2 + 2)^2 - 10 \rightarrow \text{min}$$
при ограничениях:
$$\begin{cases}
x_1^2 + x_2^2 \le 2 \\
x_1 > 0, \quad x_2 \ge 0
\end{cases}$$

\section*{Аналитическое решение}

\subsection*{Условия Куна-Таккера}
Функция Лагранжа ($\lambda_0=1$):
$$L(x, \lambda) = (10\ln x_1 - 2)^2 + 10(x_2^2 + 2)^2 - 10 + \lambda_1(x_1^2 + x_2^2 - 2)$$

Уравнения стационарности:
$$\frac{\partial L}{\partial x_1} = \frac{20(10\ln x_1 - 2)}{x_1} + 2\lambda_1 x_1 = 0$$
$$\frac{\partial L}{\partial x_2} = 40x_2(x_2^2 + 2) + 2\lambda_1 x_2 = 0$$

\subsection*{Стационарная точка}
Рассмотрев случай активного ограничения $g_3(x)$ ($x_2 = 0$) и пассивного $g_1(x)$ ($\lambda_1 = 0$):

Из второго уравнения: $\lambda_3 = 0$.

Из первого: $10\ln x_1 - 2 = 0 \implies x_1 = e^{0.2} \approx 1.221$

Проверка допустимости: $(e^{0.2})^2 + 0^2 - 2 = e^{0.4} - 2 \approx -0.508 < 0$ ✓

\textbf{Решение:} $x^* = (e^{0.2}, 0) \approx (1.221, 0)$ при $f(x^*) = 30$

\section*{Численное решение методами Python}

\begin{lstlisting}
import numpy as np
from scipy.optimize import minimize
import matplotlib.pyplot as plt

def objective(x):
    x1 = max(x[0], 1e-9)
    return (10 * np.log(x1) - 2)**2 + 10 * (x[1]**2 + 2)**2 - 10

def constraint1(x):
    return 2 - (x[0]**2 + x[1]**2)

bounds = ((1e-9, None), (0, None))
cons = {'type': 'ineq', 'fun': constraint1}

# Численная минимизация
res = minimize(objective, [1.0, 0.5], method='SLSQP', 
               bounds=bounds, constraints=cons)

print(f"x*: [{res.x[0]:.4f}, {res.x[1]:.4f}]")
print(f"f(x*): {res.fun:.4f}")
\end{lstlisting}

\section*{Результаты}

\begin{itemize}
    \item \textbf{Аналитическое решение:} $x^* = (1.2214, 0)$, $f(x^*) = 30$
    \item \textbf{Численное решение (SLSQP):} совпадает с аналитическим
    \item \textbf{Гессиан в $x^*$:} положительно определен (локальный минимум)
\end{itemize}

\section*{Выводы}

\begin{enumerate}
    \item Метод SLSQP надежно находит локальный экстремум при наличии ограничений
    \item Активное ограничение $x_2 = 0$ существенно для оптимального решения
    \item Нарушение граничного условия $x_1 > 0$ приводит к недопустимым решениям
    \item Графическое представление помогает верифицировать результаты оптимизации
\end{enumerate}
