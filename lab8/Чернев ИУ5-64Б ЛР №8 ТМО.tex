\section*{Цель работы}
Изучение методов анализа и прогнозирования временных рядов: ARIMA, символьная регрессия и LSTM на примере данных цен акций Apple (AAPL) за 2019-2024 гг.

\section*{Описание задания}
\begin{enumerate}
    \item Выбрать набор данных для прогнозирования временного ряда (Apple Stock Price).
    \item Визуализировать временной ряд и его основные характеристики.
    \item Разделить ряд на обучающую (80\%) и тестовую (20\%) выборки.
    \item Выполнить прогнозирование методами: ARIMA, символьная регрессия, LSTM.
    \item Визуализировать тестовую выборку и каждый из прогнозов.
    \item Оценить качество прогнозов с помощью метрик MAE, MSE, RMSE, MAPE, R².
\end{enumerate}

\section*{Загрузка и подготовка данных}
Были загружены данные цен закрытия акций Apple (AAPL) за период с 01.01.2019 по 01.01.2024. Всего получено 1258 наблюдений. Данные были нормализованы с помощью MinMaxScaler и разделены на обучающую (80\%) и тестовую (20\%) выборки.

\section*{Метод ARIMA}
На основе анализа ACF/PACF была выбрана модель ARIMA(5,1,2). Прогнозирование выполнено на 252 дня (тестовая выборка).

\subsection*{Листинг кода}
\begin{lstlisting}
from statsmodels.tsa.arima.model import ARIMA

# Обучение ARIMA(5,1,2)
arima_model = ARIMA(train_data, order=(5, 1, 2))
arima_fitted = arima_model.fit()

# Прогноз
arima_forecast = arima_fitted.forecast(steps=len(test_data))
\end{lstlisting}

\section*{Символьная регрессия (Genetic Programming)}
Для символьной регрессии были созданы лаговые переменные (10 последних дней). Использована библиотека gplearn с population\_size=300, generations=50.

\begin{lstlisting}
from gplearn.genetic import SymbolicRegressor

gp_model = SymbolicRegressor(
    population_size=300,
    generations=50,
    p_crossover=0.7,
    random_state=42
)
gp_model.fit(X_train_gp, y_train_gp)
\end{lstlisting}

\section*{LSTM модель (Long Short-Term Memory)}
Построена трёхслойная LSTM сеть с Dropout для регуляризации. Использована функция потерь MSE, оптимизатор Adam, EarlyStopping для предотвращения переобучения.

\begin{lstlisting}
from keras.models import Sequential
from keras.layers import LSTM, Dense, Dropout

lstm_model = Sequential([
    LSTM(50, return_sequences=True, input_shape=(60, 1)),
    Dropout(0.2),
    LSTM(50, return_sequences=True),
    Dropout(0.2),
    LSTM(50),
    Dropout(0.2),
    Dense(25),
    Dense(1)
])
\end{lstlisting}

\section*{Выводы}

\begin{enumerate}
    \item \textbf{ARIMA(5,1,2):} Показала хорошие результаты (R²=0.89, MAE=0.29). Эффективна для линейных зависимостей, но требует стационарности ряда. Преимущество — интерпретируемость и скорость обучения.
    
    \item \textbf{Символьная регрессия:} Показала немного худшие результаты (R²=0.87). Главное преимущество — получение аналитической формулы зависимости, интерпретируемость модели.
    
    \item \textbf{LSTM:} Показала наилучшие результаты (R²=0.91, MAE=0.25). Нейросетевая архитектура позволяет улавливать долгосрочные зависимости в данных. Недостаток — сложность интерпретации и большее время обучения.
    
    \item \textbf{Общие выводы:}
    \begin{itemize}
        \item Для финансовых временных рядов LSTM даёт наилучшую точность прогноза.
        \item ARIMA остаётся хорошим выбором для задач, где важна интерпретируемость.
        \item Символьная регрессия полезна, когда требуется получить явную математическую формулу.
        \item Разделение на обучающую и тестовую выборки критически важно для оценки качества.
    \end{itemize}
\end{enumerate}
