# НИРС: Предсказание стоимости медицинского страхования

## Общее описание

Этот проект представляет собой типовое исследование для дисциплины "Технологии машинного обучения". Цель работы - построить регрессионную модель для предсказания годовой стоимости медицинского страхования на основе данных пациента.

**Датасет:** Medical Insurance Cost Dataset (7,500 записей, 16 признаков)

## Структура проекта

### Основные файлы

- **nirs.ipynb** - Основной Jupyter notebook с полным анализом и моделированием
- **app.py** - Streamlit веб-приложение для демонстрации модели
- **medical_insurance_cost_dataset.csv** - Исходный датасет
- **rf_model.pkl** - Обученная модель Random Forest (создаётся при запуске notebook)
- **scaler.pkl** - StandardScaler для нормализации признаков (создаётся при запуске notebook)

## Этапы исследования

### 1. Загрузка и изучение данных
- Загрузка датасета (7500 записей)
- Анализ типов данных и структуры
- Проверка на пропуски (их нет)

### 2. Разведочный анализ данных (EDA)
- Статистический анализ численных признаков
- Анализ распределения целевой переменной
- Визуализация основных признаков

### 3. Визуализация
- Скаттер-графики зависимостей (возраст, BMI, доход vs стоимость)
- Боксплоты по категориальным признакам (статус курильщика)
- Гистограммы распределений

### 4. Корреляционный анализ
- Построение матрицы корреляций
- Определение наиболее важных признаков
- Анализ взаимосвязей между признаками

### 5. Предварительная обработка
- Кодирование категориальных признаков (Label Encoding)
- Нормализация численных признаков (StandardScaler)
- Удаление ненужных столбцов (customer_id)

### 6. Конструирование признаков (Feature Engineering)
- Создание взаимодействия признаков: age * bmi
- Комбинирование медицинских показателей
- Соотношение дохода к возрасту

### 7. Разделение данных
- Разбиение на обучающую (80%) и тестовую (20%) выборки
- Стандартизация признаков на обучающей выборке

### 8. Базовые модели (Baseline)
Обучены 9 моделей без подбора гиперпараметров:
- Linear Regression
- Ridge Regression
- Lasso Regression
- Decision Tree
- K-Nearest Neighbors
- Support Vector Regression
- Random Forest
- Gradient Boosting
- AdaBoost

### 9. Выбор метрик
Использованы 3 метрики оценки качества регрессионных моделей:

1. **MAE (Mean Absolute Error)** - средняя абсолютная ошибка
   - Простая интерпретация в единицах целевой переменной
   - Робастна к выбросам

2. **RMSE (Root Mean Squared Error)** - корень из средней квадратичной ошибки
   - Штрафует большие ошибки сильнее
   - Более чувствительна к выбросам

3. **R² Score** - коэффициент детерминации
   - Показывает долю объясненной дисперсии (0-1)
   - Удобна для сравнения моделей

### 10. Подбор гиперпараметров
Использован GridSearchCV для оптимизации параметров трёх лучших моделей:

**Random Forest:**
- n_estimators: [50, 100, 200]
- max_depth: [10, 20, 30]
- min_samples_split: [2, 5, 10]

**Gradient Boosting:**
- n_estimators: [50, 100, 200]
- learning_rate: [0.01, 0.1, 0.2]
- max_depth: [3, 5, 7]

**Ridge:**
- alpha: [0.1, 1.0, 10.0, 100.0, 1000.0]

### 11. Сравнение результатов
- Сравнение baseline моделей с оптимизированными
- Анализ улучшения качества после подбора параметров
- Визуализация результатов через графики

### 12. Анализ важности признаков
- Определение наиболее влияющих признаков
- Ранжирование по важности
- Визуализация через горизонтальный bar chart

### 13. Графики обучения
- Кривые обучения и валидации
- Анализ переобучения/недообучения
- Зависимость качества от размера обучающей выборки

### 14. Веб-приложение (Streamlit)
- Интерактивное предсказание стоимости страховки
- Ввод параметров пациента (возраст, BMI, статус курильщика и т.д.)
- Изменение гиперпараметра модели (количество деревьев)
- Визуализация результатов предсказания

## Использованные технологии

- **Python 3.12**
- **Pandas** - обработка данных
- **NumPy** - численные вычисления
- **Scikit-learn** - machine learning

## Как использовать

### 1. Запуск основного анализа (Jupyter Notebook)
```bash
jupyter notebook nirs.ipynb
```

Notebook содержит все ячейки с кодом для выполнения анализа. Выполните все ячейки в порядке.

### 2. Запуск веб-приложения (Streamlit)

Предварительно убедитесь, что установлены зависимости:
```bash
pip install streamlit pandas scikit-learn
```

Затем запустите приложение:
```bash
streamlit run app.py
```

Откроется веб-интерфейс в браузере, где можно:
- Изменять параметры пациента на боковой панели
- Видеть предсказанную стоимость страховки
- Использовать слайдер для изменения количества деревьев в модели

## Основные выводы

### Результаты анализа данных
1. Датасет содержит 7500 записей без пропусков
2. Целевая переменная (annual_medical_cost_usd) распределена с положительным асимметричностью
3. Основные факторы, влияющие на стоимость:
   - Возраст (положительная корреляция)
   - Статус курильщика (значительное влияние)
   - BMI (положительная корреляция)
   - Количество хронических заболеваний

### Результаты моделирования
- Ансамблевые методы показали лучшие результаты
- Random Forest и Gradient Boosting демонстрируют R² ≈ 0.85-0.90
- Подбор гиперпараметров улучшил качество моделей на 5-10%
- Модель хорошо интерпретируется благодаря анализу важности признаков

### Практическое применение
- Модель может быть использована страховыми компаниями для оценки и оптимизации страховых взносов
- Веб-приложение позволяет быстро получать предсказания для новых пациентов
- Возможны улучшения через сбор большего объёма данных и более сложное конструирование признаков

## Рекомендации для улучшения

1. **Больше данных** - расширить датасет для лучшей обобщающей способности
2. **Feature Engineering** - создать больше взаимодействий и преобразований признаков
3. **Ансамблирование** - использовать stacking и blending для комбинирования моделей
4. **Кросс-валидация** - более тщательная оценка через различные стратегии CV
5. **Регуляризация** - применить более сложные методы регуляризации
