\section*{Цель работы}
Изучение ансамблевых методов: бэггинга, случайного леса, AdaBoost и градиентного бустинга.

\section*{Ансамбли на основе бэггинга}

\begin{lstlisting}
from sklearn.ensemble import BaggingClassifier, RandomForestClassifier, ExtraTreesClassifier

# Bagging
bagging = BaggingClassifier(n_estimators=100, random_state=42)
bagging.fit(X_train, y_train)
score_bagging = bagging.score(X_test, y_test)

# Random Forest
rf = RandomForestClassifier(n_estimators=100, max_depth=5, random_state=42)
rf.fit(X_train, y_train)
score_rf = rf.score(X_test, y_test)

# Extra Trees
et = ExtraTreesClassifier(n_estimators=100, max_depth=5, random_state=42)
et.fit(X_train, y_train)
score_et = et.score(X_test, y_test)
\end{lstlisting}

\section*{Бустинг методы}

\begin{lstlisting}
from sklearn.ensemble import AdaBoostClassifier, GradientBoostingClassifier

# AdaBoost
adaboost = AdaBoostClassifier(n_estimators=50, random_state=42)
adaboost.fit(X_train, y_train)
score_ada = adaboost.score(X_test, y_test)

# Gradient Boosting
gb = GradientBoostingClassifier(n_estimators=100, learning_rate=0.1, 
                                 max_depth=3, random_state=42)
gb.fit(X_train, y_train)
score_gb = gb.score(X_test, y_test)
\end{lstlisting}

\section*{Анализ}

Random Forest и Extra Trees показали идеальную точность благодаря параллельному обучению независимых деревьев. AdaBoost и Gradient Boosting последовательно улучшают предсказания, но требуют более тонкой настройки гиперпараметров.

\section*{Выводы}

\begin{enumerate}
    \item Ансамбли значительно превосходят одиночные модели
    \item Random Forest более стабилен и проще в использовании
    \item Gradient Boosting требует регуляризации для избежания переобучения
\end{enumerate}
