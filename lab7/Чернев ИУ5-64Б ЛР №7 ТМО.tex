\section*{Цель работы}
Изучение ансамблей моделей машинного обучения: стекинг и многослойный персептрон (MLP) на примере датасета Diabetes (прогнозирование прогрессии диабета).

\section*{Описание задания}
\begin{enumerate}
    \item Выбрать набор данных для решения задачи регрессии (Diabetes Dataset).
    \item При необходимости выполнить предобработку данных (масштабирование).
    \item Разделить выборку на обучающую (80\%) и тестовую (20\%) с помощью \texttt{train\_test\_split}.
    \item Обучить ансамблевые модели:
    \begin{itemize}
        \item Стекинг (Stacking) — комбинация нескольких базовых моделей с мета-моделью.
        \item Многослойный персептрон (MLP) — нейросетевая модель.
    \end{itemize}
    \item Оценить качество моделей с помощью метрик MSE, MAE, R².
    \item Сравнить качество полученных моделей.
\end{enumerate}

\section*{Загрузка и подготовка данных}
Был загружен датасет Diabetes, содержащий 442 образца и 10 признаков. Целевая переменная — количественная характеристика прогрессии диабета. Данные были нормализованы с помощью StandardScaler и разделены на обучающую (80\%) и тестовую (20\%) выборки.

\section*{Стекинг (Stacking)}

Стекинг — это метод ансамблирования, который комбинирует предсказания нескольких базовых моделей (уровень 0) с помощью мета-модели (уровень 1). В данной работе в качестве базовых моделей использовались:
\begin{itemize}
    \item LinearRegression
    \item Ridge(alpha=1.0)
    \item Ridge(alpha=10.0)
    \item Ridge(alpha=100.0)
\end{itemize}
В качестве мета-модели использовалась Ridge(alpha=1.0).

\subsection*{Листинг кода}
\begin{lstlisting}
class StackingRegressor:
    def __init__(self, base_models, meta_model):
        self.base_models = base_models
        self.meta_model = meta_model
    
    def fit(self, X, y):
        meta_features = np.zeros((X.shape[0], len(self.base_models)))
        for i, model in enumerate(self.base_models):
            model.fit(X, y)
            meta_features[:, i] = model.predict(X)
        self.meta_model.fit(meta_features, y)
        return self
    
    def predict(self, X):
        meta_features = np.zeros((X.shape[0], len(self.base_models)))
        for i, model in enumerate(self.base_models):
            meta_features[:, i] = model.predict(X)
        return self.meta_model.predict(meta_features)
\end{lstlisting}

\section*{Многослойный персептрон (MLP)}

Многослойный персептрон — это нейронная сеть с одним или несколькими скрытыми слоями. В данной работе использовалась архитектура: 10 → 100 → 100 → 50 → 1 с функцией активации ReLU и оптимизатором Adam. Для предотвращения переобучения использовался EarlyStopping.

\begin{lstlisting}
from sklearn.neural_network import MLPRegressor

mlp_model = MLPRegressor(
    hidden_layer_sizes=(100, 100, 50),
    activation='relu',
    solver='adam',
    max_iter=1000,
    random_state=42,
    early_stopping=True,
    validation_fraction=0.1,
    n_iter_no_change=50,
    verbose=0
)
\end{lstlisting}

\section*{Выводы}

\begin{enumerate}
    \item \textbf{Стекинг (Stacking):} Показал лучшие результаты (MSE=2900.24, MAE=42.79, R²=0.453). Комбинирование предсказаний нескольких базовых моделей через мета-модель позволяет улучшить обобщающую способность. Преимущество — возможность использовать разнородные модели.
    
    \item \textbf{Многослойный персептрон (MLP):} Показал немного худшие результаты (MSE=2939.13, MAE=43.51, R²=0.445). Нейросетевые модели требуют тщательной настройки гиперпараметров (количество слоёв, нейронов, скорость обучения) и большего объёма данных для достижения высоких результатов.
    
    \item \textbf{Общие выводы:}
    \begin{itemize}
        \item Стекинг оказался более эффективным на данном датасете, чем отдельная нейросетевая модель.
        \item Обе модели показали умеренное качество (R²~0.45), что объясняется сложностью предсказания прогрессии диабета по 10 признакам.
        \item Для улучшения результатов можно использовать более сложные мета-модели, добавлять больше базовых моделей или применять нейросетевые архитектуры с регуляризацией.
    \end{itemize}
\end{enumerate}
