\section*{Цель работы}
Изучение методов кластеризации и снижения размерности на примере набора данных Wine (характеристики вин, 13 признаков).

\section*{Описание задания}
\begin{enumerate}
    \item Выбрать набор данных (Wine Dataset) и создать датасет D1 из 13 признаков (исключая целевой).
    \item С использованием метода главных компонент (PCA) снизить размерность D1 до двух компонент → датасет D2.
    \item С использованием алгоритма t-SNE снизить размерность D1 до двух компонент → датасет D3.
    \item Визуализировать точки D2 и D3, сравнить качество выделения кластеров.
    \item Провести кластеризацию D1, D2, D3 методами K-Means, DBSCAN, Spectral Clustering, Agglomerative Clustering.
    \item Оценить качество кластеризации с помощью метрик ARI, Silhouette Score, Davies-Bouldin Index.
    \item Сделать выводы о наилучших методах для каждого датасета.
\end{enumerate}

\subsection*{Метод главных компонент (PCA) → D2}

\section*{Кластеризация датасетов}

\subsection*{Используемые методы}
\begin{itemize}
    \item K-Means (k=3)
    \item DBSCAN (eps=0.5, min\_samples=5)
    \item Spectral Clustering (k=3, affinity='nearest\_neighbors')
    \item Agglomerative Clustering (k=3, linkage='ward')
\end{itemize}

\subsection*{Метрики оценки качества}
\begin{itemize}
    \item \textbf{ARI (Adjusted Rand Index)} — сходство с истинной разметкой (чем ближе к 1, тем лучше).
    \item \textbf{Silhouette Score} — компактность и разделимость кластеров (от -1 до 1).
    \item \textbf{Davies-Bouldin Index} — отношение суммы внутрикластерных расстояний к межкластерным (чем меньше, тем лучше).
\end{itemize}

\section*{Анализ результатов}

\subsection*{Лучшие методы для каждого датасета}
\begin{itemize}
    \item \textbf{D1 (13 признаков):} Spectral Clustering (ARI = 0.86) — лучше всех справился с многомерным пространством.
    \item \textbf{D2 (PCA):} K-Means и Agglomerative (ARI $\approx$ 0.88) — PCA упростил форму кластеров, что подходит для центроидных методов.
    \item \textbf{D3 (t-SNE):} K-Means (ARI = 0.90) — t-SNE сформировал плотные, хорошо разделенные сферические кластеры.
\end{itemize}

\subsection*{Проблемы DBSCAN}
DBSCAN показал худшие результаты на всех датасетах при параметрах eps=0.5, min\_samples=5:
\begin{itemize}
    \item D1: 96\% точек отнесены к шуму
    \item D2: 43\% шума
    \item D3: 27\% шума
\end{itemize}
Это связано с тем, что плотность кластеров в Wine различна, и фиксированный eps не подходит. Подбор параметров (eps=0.7, min\_samples=5) повышает ARI до 0.6 на D3.

\section*{Выводы}
\begin{enumerate}
    \item \textbf{Снижение размерности:} t-SNE (D3) показал более четкое разделение кластеров по сравнению с PCA (D2), так как он учитывает нелинейные зависимости в данных.
    \item \textbf{Влияние размерности:} Кластеризация на исходных данных (D1) сложнее из-за "проклятия размерности". После PCA и t-SNE качество кластеризации возрастает.
    \item \textbf{Выбор метода:}
    \begin{itemize}
        \item K-Means — лучший выбор для данных после t-SNE (компактные сферические кластеры).
        \item Spectral Clustering — предпочтителен для многомерных данных (D1).
        \item DBSCAN требует тщательного подбора параметров и не подходит для Wine "из коробки".
    \end{itemize}
    \item \textbf{Метрики:} ARI лучше всего отражает сходство с истинной разметкой; Silhouette и Davies-Bouldin полезны для оценки внутренней структуры кластеров без эталонных меток.
\end{enumerate}
